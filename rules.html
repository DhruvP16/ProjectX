Battleship

A two-player strategy game where each player tries to destroy the other player's fleet.

Goal of the Game

Each player secretly places five ships on their own board. Players then take turns firing at squares on the opponent's board.

The first player to find and destroy all five enemy ships wins the game.

The Fleet

Each player has the following ships:

  • Carrier: 5 squares
  • Battleship: 4 squares
  • Cruiser: 3 squares
  • Submarine: 3 squares
  • Destroyer: 2 squares

Placing Ships

Player 1 places all five ships first. After Player 1 finishes, the computer is passed to Player 2 so they can place their ships.

Ships may be placed horizontally or vertically. Ships cannot overlap another ship or extend outside the board.

Move the mouse over the board to preview the current ship. A green preview means the ship can be placed there. A red preview means the placement is not allowed.

  • Rotate Ship: Changes the current ship between horizontal and vertical placement.
  • Random Fleet: Clears the current placement and randomly places all five ships.

After both players finish placing their ships, the computer is passed back to Player 1 and the firing portion of the game begins.

Taking Turns

Player 1 fires first. To fire, select a square on the opponent's board.

After a valid shot is taken, the turn changes to the other player. A square that has already been selected cannot be fired upon again.

The game relay displays whether the shot was a hit, a miss, or whether a ship was completely destroyed.

Hits, Misses, and Destroyed Ships

A shot is a hit when it lands on a square occupied by an enemy ship. A shot is a miss when it lands on an empty water square.

A ship is destroyed when every square occupied by that ship has been hit. When this happens, the game relay announces the name of the destroyed ship.

Board Colors

  • Light blue: An unselected water square.
  • White: A shot that missed.
  • Red: A ship square that was hit, but the ship has not been completely destroyed.
  • Gray: A ship that has been completely destroyed.
  • Dark gray during placement: A ship belonging to the player currently placing ships.

Ships remain hidden during the firing portion of the game so the opponent cannot see their locations.

Winning the Game

The game ends when one player destroys all five of the opponent's ships.

After the game ends, a message displays the winner and asks whether the players would like to play again.

Selecting Yes begins a new game. Selecting No keeps the completed game visible.

Game Buttons

  • Rotate Ship: Changes the direction of the current ship.
  • Random Fleet: Clears the current placement and randomly places all five ships.
  • New Game: Erases the current game and begins a new one. A confirmation message appears before the game is erased.
  • Rules: Opens this rules window.
Important: Do not look at the other player's ship placement. Pass the computer whenever the game instructs you to do so.
